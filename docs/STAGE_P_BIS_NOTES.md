## PB-D1 — Sepolia is the live-broadcast target (closes the P-D1 live-target deferral; user-adjudicated 2026-07-11)

The load-bearing criterion is 12-second block parity: every protocol constant is block-denominated (OQ-3 / OQ-4 / OQ-5 — `BLOCKS_PER_DAY = 7_200` assumes 12s slots), so any ~2s-block L2 testnet would distort every time-gated behavior (halving eras, epochs, veto windows, qualification cliffs) by ~6×, restricting the field to Ethereum L1 testnets. Sepolia: 12s slots, the standard application testnet (mature faucet / Etherscan / wallet tooling), canonical Permit2 deployed, Balancer V3 reference deployments present (orientation only — Aureum deploys its own Vault + Router per P-D26). Hoodi rejected (validator/staking-focused Holesky successor; thinner application tooling). Tenderly-only rejected (private — fails the public live-frontend goal; it remains the private mainnet-fork complement per the Stage-P/Q notes). Execution hedge: testnet infra states drift, so workstream B opens with a verify pass (faucet availability, Permit2 presence at the canonical address, explorer contract-verification flow) before any broadcast sub-step is drafted.
